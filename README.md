## راهنمای نصب و اجرای پروژه راد 

### ۱. نصب Node.js
#### اطمینان حاصل کنید که Node.js بر روی سیستم شما نصب شده است. می‌توانید با اجرای دستور زیر نسخه Node.js را بررسی کنید:
```bash
node -v
```

### ۲. نصب وابستگی‌ها
#### به پوشه پروژه خود بروید و وابستگی‌ها را نصب کنید:
```bash
cd raad_frontend
```
```bash
npm install --force
```


### ۳. اجرای پروژه
#### قبل از اجرای پروژه لازم است فایل env. در روت پروژه ایجاد شود و متغیر های زیر در فایل اضافه شود
```bash
APP_API_URL=127.0.0.1:8082
APP_VERSION=$npm_package_version
```

#### برای اجرای پروژه در حالت توسعه از دستور زیر استفاده کنید:

```bash
npm run start
```
#### پس از اجرای این دستور، Vite یک سرور محلی راه‌اندازی می‌کند و آدرس http://localhost:3100 را به شما می‌دهد. می‌توانید با باز کردن این آدرس در مرورگر، پروژه خود را مشاهده کنید.(اگر با localhost خطای سرور مواجه شدید با 127.0.0.1 تست کنید)
### ۴. بیلد پروژه
#### برای ایجاد نسخه تولیدی پروژه، از دستور زیر استفاده کنید:
```bash
npm run build
```
#### این دستور یک پوشه به نام build ایجاد می‌کند که شامل فایل‌های بیلد شده برای تولید است.

### ۵. دیپلوی پروژه
#### برای اجرای پروژه بیلد شده پروژه، می‌توانید از وب سرور vite استفاده کنید:
```bash
npm run preview
```
#### پس از اجرای این دستور، Vite یک سرور محلی راه‌اندازی می‌کند و آدرس http://localhost:3200 را به شما می‌دهد. می‌توانید با باز کردن این آدرس در مرورگر، پروژه خود را مشاهده کنید.
